Privacy notice

This notice describes Google data handling in the owner-operated Clawdo installation. It applies to that installation's Google integration.

Information accessed

With the account owner's authorization, Clawdo can retrieve Gmail search results and selected messages or threads, Calendar events, Drive file metadata, Google Docs text and selected Google Sheets ranges. Access uses the two specifically configured accounts and the tool permissions described on the overview page.

The assistant account's Google consent includes broader Drive read/write permission. Clawdo exposes only reads and edits to existing Docs and Sheet ranges. Personal tools remain read-only. Gmail sending and Calendar writes are disabled for both accounts.

Purpose and AI processing

Google data is used to answer the owner's requests and perform the explicitly requested features available in this installation. Relevant content can be included in model requests through OpenRouter. The installation is configured to require the Azure EU provider route, zero data retention and no data collection, with provider fallback disabled. These are the configured processing controls; third-party providers operate under their applicable policies.

This installation does not sell Google data, use it for advertising, or use it to train or improve general-purpose AI or machine-learning models. It uses local text search for memory and no external embedding service.

Storage and retention

OAuth refresh tokens are stored in an encrypted local keyring outside the model's workspace. Conversation history and tool results can be stored in the local assistant installation. Operator backups are encrypted. Local host security remains the owner's responsibility.

There is no automatic deletion schedule in this installation. Locally retained history, memory and backups remain until the owner removes them. Removing an item from active history does not automatically remove older encrypted backup copies.

Control and deletion

The account owner can revoke this application's Google access through Google Account connections. Revocation prevents future authorized API access; it does not erase previously retained local history or backups.

For removal of locally stored tokens, conversation data or backups, contact the installation operator through the support email displayed on Google's consent screen. The operator can disconnect the accounts, stop the installation and remove the relevant local data and retained copies.

These information pages

These static pages do not request Google authorization, collect Google account data or connect visitors to Clawdo. They include no forms, analytics code or tracking scripts. The hosting provider may process ordinary network and security logs.

Questions and changes

Use the user-support contact on Google's consent screen for privacy questions. This notice must be updated if this installation's access, processing providers or retention practices change.

Google API data use is subject to the Google API Services User Data Policy, including its Limited Use requirements.
